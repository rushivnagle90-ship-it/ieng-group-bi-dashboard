# ieng-group-bi-dashboard
Business Intelligence &amp; Analytics Dashboard developed for IEng Group using Power BI, SQL Server, DAX, and Excel. The project includes Star Schema data modeling, KPI reporting, trend analysis, Row-Level Security (RLS), SQL-based analytics, and executive dashboards focused on sales, profitability, and operational insights.

 Built BI & Analytics solution for an international EPC & O&M infrastructure company. 
•  Designed Star Schema (SQL Server + Power BI); KPI dashboards for Revenue, Profit, Margin & 
Sales. 
•  Implemented RLS for region-based access; built executive reports and KPI governance 
framework.
