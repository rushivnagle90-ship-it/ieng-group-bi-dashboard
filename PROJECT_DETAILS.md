# IEng Group – Business Intelligence Dashboard

Business Intelligence & Analytics Dashboard developed for IEng Group using Power BI, SQL Server, DAX, and Excel.

## Project Highlights
- Star Schema Data Modeling
- KPI Reporting & Trend Analysis
- Sales Performance Dashboard
- Row-Level Security (RLS)
- SQL-Based Analytics
- Executive Summary Reports
- KPI Register & Governance

## KPIs Included
- Total Revenue
- Total Profit
- Profit Margin %
- Return Rate %
- Average CSAT Score
- Average Delivery Time
- Total Orders
- Completed Orders %

## Tech Stack
Power BI • SQL Server • DAX • Power Query • Excel

## Skills Demonstrated
Business Intelligence • Data Analytics • Dashboard Development • SQL • Data Modeling • Reporting Automation
